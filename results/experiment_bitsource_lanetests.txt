two-lane generator P(flip_t) = 1/2 + (-1)^t eps, each window starting on a RANDOM lane
alpha = 0.05;  200000 null windows (calibration) and 100000 windows per eps row; eps = 0 row is a FRESH null batch (attained size)
CT     = d_r on the run-length histogram, q = (16, 8, 4, 2, 1, 1), MC cut
pair   = non-overlapping pair chi-square (Knuth serial), 3 df; 'pair(chi2)' uses the asymptotic cut 7.8147
parity = |D - E0 D|, D = flips at even positions - flips at odd positions; 'parity(exact)' uses the exact Binomial(w-1, 1/2) cut
se     = MC standard error; for MC-cut columns it includes the null-batch calibration error (bootstrap), for analytic cuts it is binomial only
