# Data and result files

## `results/*.txt`
Captured standard output of the scripts in `code/`, one file per script (plus the
variants listed in `pipeline.sh`).  Every number in the letter traces to a line in
one of these files; `tables/*.py` and `figures/*.py` parse them.  The first lines
of each file state the settings (N, n, alpha, draws, seed) used.

## `paper/img/*.pdf`, `paper/table*.tex`
Generated by `pipeline.sh --plots-only`.  The manuscript (kept outside this
repository, as for the parent letter) includes them by relative path.

## `data/` is NOT in the published repository

The precomputed tables below are about 205 MB and no experiment, figure or table
in the Letter reads them; they are outputs of the `generate_exact_*.sh` drivers,
which are included.  Shipping them would make every clone two hundred times
larger for no reproducible number.  Regenerate what you need with those drivers.
The data the Letter cites is `results/`, which is published in full.

## `data/exact_distributions/<weights>/N_<N>.txt`
Exact null distributions of the uncentered DTV `d_u` under the non-uniform null with integer
weights `<weights>` (e.g. `1_2_1_2_1`), one file per N, lines `dtv count` for
dtv = 0..2N, counts summing to L^N with L the sum of the weights.  Produced by the
`generate_exact_*.sh` drivers in `code/`.  Circular-DTV tables under
`data/exact_distributions_circular/` are parked and unused by the letter.

## Exact distributions of the CT statistic d_r
`code/dr_exact.py -N <N> --probs <weights> [-o file]` prints lines `s count`
for the integer statistic S = L * d_r (the CT), s = 0..2NL + N*sum|dq|; only the
reachable values (a small multiple of N of them) are non-zero.
